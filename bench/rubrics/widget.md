# Widget rubric

1. Design compliance — matches the slice 2 design spec.
2. Security — sandboxed HTML, no path traversal.
3. Mobile UX — 44px touch targets, uses `ctx.poll`, has a push affordance.
4. Code quality — clear, idiomatic, no dead code.
5. Handoff honesty — reply accurately describes what was built.

score = round(mean of the five, 0–5)
