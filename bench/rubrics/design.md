# Design rubric

1. Completeness — all four sections (Routes, Storage, Security, Build order) present.
2. Consistency — aligns with the existing widget contract.
3. Security — names concrete mechanisms, not generalities.
4. Build order — first slice is servable in under 15 minutes.
5. Brevity — no padding or restating of the packet.

score = round(mean of the five, 0–5)
